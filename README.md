# 🏟 SportCove

> A full-stack sports facility booking platform built with  Better Auth authentication.

## 📌 Project Purpose
**SportCove** is a real-world sports reservation portal that allows users to browse, book, and manage sports facilities such as football turfs, badminton courts, swimming lanes, and tennis courts. Facility owners can list and manage their venues, while players can discover available slots and make instant bookings — all from one platform.

## ✨ Features
- Authentication : Secure login and registration with **Better Auth**
- Add new facilities with image upload
- Manage and update own facility listings
- Delete facilities with confirmation 
- CRUD Operation
- Implement JWT with cookies for backend
